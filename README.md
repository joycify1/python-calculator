# python-calculator
My first Python project - a simple command-line calculator.

## Features

The calculator currently supports:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Modulus (%)
- Exponentiation (**)

## Concepts I practiced

- Taking user input
- Type casting (converting input to numbers)
- Float data types
- Variables
- Conditional statements (if / elif / else)
- Arithmetic operators
- Basic Python syntax

## How to run

1. Make sure Python is installed.
2. Download `calculator.py`.
3. Run:

```bash
python calculator.py
